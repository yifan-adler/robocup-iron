## 小任务实测

- 搭环境并完成 onboarding：耗时、是否独立完成。
- 选择一个 XML，解释 env、instr、nl：结论。
- 选择一条失败日志，判断问题属于哪一层：结论。
- 在不改代码的情况下解释 `main → RDFW::Init → Run → Plan`：结论。
